# 3DRenderer

A lightweight 3D renderer built with C++ and OpenGL.

This project focuses on implementing core real-time graphics concepts from the ground up, including 3D transformations, camera controls, shaders, lighting, and rendering architecture.

## Tech Stack

- C++
- OpenGL
- GLFW
- CMake

## Goals

- Understand the basic real-time rendering pipeline
- Render and transform 3D objects
- Implement camera controls
- Work with shaders, lighting, and textures
- Build a graphics project with a clean C++ structure
